# What stays free

Dated, in the repository, because a promise on a marketing page is not checkable and this
project is about the difference.

**2026-09-01 — the commitment**

The command-line tool is free, open source, and complete. Not a trial, not a teaser, not a
capped version of something better.

Free, now and permanently:

- Scanning every cache type the manifest lists
- Deletion, with every path shown first
- All safety checks, and the ability to run them yourself
- `MANIFEST.md` and the CI check that enforces it
- The full source

**Features already in the free CLI never move behind a paid app.** If something is free today it
is free in every later version. The only way that changes is a fork by someone else, and that is
what the licence is for.

A paid app, if it ships, earns its money by being a different *shape* — not a bigger number:

- A menu bar presence and a real window
- Watching in the background and telling you when a threshold is crossed
- Browsing by project, with history
- Scheduled scans

Nobody happy in a terminal loses anything by not paying.

**What is deliberately never paid:** the manifest, the safety checks, and the dry run. Those are
the evidence that the tool is safe to run. Charging for the evidence would make the claim
worthless.
